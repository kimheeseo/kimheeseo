# 3단계 · 학습 기록과 복습

## 변경 파일
- `study-storage.js`, `study-ui.js`, `trust.js`
- 통신/무선/K-water 학습 HTML 및 기존 localStorage를 사용하던 자료 HTML
- `scripts/quiz-tests.cjs`, `scripts/quiz-study-tests.cjs`

## 변경
저장 계층을 StudyStore 한 곳으로 통합. 과목·문항 ID별 풀이 횟수, 정답·오답·채점 보류, 시간, 북마크·메모 유지. 기존 저장 키와 수치 보존, 중복 이전 방지, 숫자 타임스탬프 정상 이전. 실제 시각을 알 수 없는 과거 기록은 최근 7일 풀이량에 만들어 넣지 않음. 잘못된 백업·과목 불일치·25MB 초과 파일 거부. 가져오기 저장 실패 시 기존 값을 복구. 전체/과목별 JSON 백업 API. 초기화 시 복원되는 구기록 문제 수정.

오답 후 1일, 정답 시 3→7→14일, 다시 오답이면 1일. 기록 화면의 최근 7일은 브라우저 날짜별 실제 채점 이벤트만 계산. 보류는 정답률 분모에서 제외. 홈 복습 카드는 전체 대기 수와 현재 검증 필터 적용 가능 수를 함께 표시.

## 테스트
`node scripts/quiz-tests.cjs`: 상태·수식 실패, 간격 반복, 레거시 시각/중복 이전, 보류 제외, 백업 실제 가져오기, 과목 오적용 거부, 초기화, 중복 제출 방지를 검사. 브라우저 무선 내 학습 현황에서 7일 표·단원별 정답률·오답 TOP3·복습/내보내기/가져오기 UI 확인. 앱 콘솔 오류 0건.
