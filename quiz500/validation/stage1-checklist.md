# 통신직 준비 — 1단계 신뢰성 검증 체크리스트
작성일: 2026-11-21

## 상태 정의 및 승인
- `verified`: 원문/정답/해설의 개별 대조를 끝낸 문항만 `quiz500/status-overrides.json`의 `overrides`에서 승인. 예: `"comm:Q001": "verified"`.
- `auto`: 원문 또는 자동 추출 기반의 미검증 문항. 정답이 존재하더라도 검증 완료와 다름.
- `review`: 원문/선택지 누락, 답 없음, 깨진 그림·수식, KaTeX 오류 등. 자동 채점하지 않음.
- 현재 승인 목록은 비어 있음. 따라서 ‘검증된 문항만 풀기’가 켜진 기본 상태에서 검증 완료 0문항을 안내해야 함.

## 브라우저에서 재현
1. 통신공학 `quiz500/communication-quiz-500/` 와 무선공학 `quiz500/wireless-quiz-500/` 방문. 홈 첫 번째 통계가 `전체 / 검증 완료`로 구분되는지 확인.
2. 기본 ON 상태에서 학습 시도가 0문항 안내로 종료되고, 설정을 OFF로 바꾸면 미검증 문항이 표시되는지 확인. 재접속 시 OFF 값 유지 확인.
3. `?kind=코레일%20기출`, `?chapter=신호와%20시스템`, `?unit=0` 등 기존에 지원하던 URL이 원래 화면과 같은 필터를 유지하는지 확인.
4. 문항으로 진입하면 상태 배지와 품질 안내가 보이는지, 오류 신고 폼에 ‘정답 오류’ 등을 선택하고 메모를 적으면 GitHub Issue 생성 링크의 title/body에 문항 ID, 사유, 메모가 포함되는지 확인. 사용자가 GitHub에서 별도 제출해야 함.
5. `review` 문항을 OFF 상태에서 열면 답안을 선택하더라도 ‘채점 보류’가 표시되고 정답·오답 및 누적 통계에 반영되지 않는지 확인.
6. K-water `quiz500/kwater-exams/` 에서 기본 ON 시 검증 0문항 안내, OFF 시 신규 2~4회차 풀이, 원본 40문항 참조 확인.
7. KaTeX 수식 `\\(x^2+1\\)`을 담은 테스트 문항을 선택해 렌더 확인. 잘못된 수식 명령은 상태 `review` 및 채점 보류. CDN 차단 시에도 일반 텍스트 문항 학습에는 영향 없어야 함.
8. F12 Console/Network를 열고 통신공학·무선공학·K-water의 홈→문항→제출→문제은행→홈을 차례로 이동해 오류(특히 TypeError/ReferenceError/KaTeX CDN load)를 확인. HTML/JS 정적 문법 검사가 실제 브라우저 콘솔 검증을 대체하지는 않음.
9. 360px 화면에서 체크박스, 신고 드롭다운·메모, 상태 배지가 가려지지 않는지 확인.

## 정적 검증 요약
- 4개 원천 문항 JSON: 1,762 + 1,074 + 120 + 40 = 2,996개, 모두 `status` 가 존재.
- 3개 학습 HTML 및 공통 JS 파서 테스트 통과.
- 검증 승인 오버라이드의 단일 출처 및 `review` 강제 보류 단위테스트 통과.
