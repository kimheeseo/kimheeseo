# 4단계 모의고사·직렬별 구성 검증 체크리스트
작성: 2026-11-21

## 검증 원칙
- 모의고사 `mock-exam/index.html`은 `QuizTrust.status(...)=verified`이며 `QuizTrust.gradeable(...)`인 문항만 출제한다.
- 승인 `status-overrides.json`이 빈 현재 상태에서는 출제가능 0건, ‘모의고사 시작’ 비활성화가 **정상**이다.
- 모의고사 과목·문항 수·제한 시간은 자체 연습용 사용자 설정이다. 공식 직렬별 채용 전형과 일치하지 않는 한 직접 비교할 수 없다.

## 수동 테스트
1. `mock-exam/`에 접속해 기본 선택에서 출제가능 0개, 시작 비활성 확인.
2. 검토 완료한 테스트 문항만 `status-overrides.json`에 `"comm:Q001": "verified"`와 같이 승인 후 재접속 (검증 작업을 완료하지 않은 문항은 테스트를 위한 목적으로도 무단 verified 지정 금지).
3. 승인된 문항 수 이상은 시작할 수 없어야 한다. 조건 충족 시 무작위 출제되고 전 문항 풀이·이전/다음·타이머 제출 확인.
4. 제출 시 100점 환산, 단원별 정답률, 오답 해설 및 개인 기록(`quiz500_study_v1_mock`) 확인.
5. `exam-subjects/`에서 5개 직렬, 확인된 일부 합격선·출처·확인일, 과목수/시간 **공고 확인 필요**, K-water 참고 민간 40문항/40분을 구분해서 확인.
6. 목표 기관 설정 후 모의고사 점수와 합격선 비교(공식 9급/비공식 7급/미확정 타 기관)를 확인. 비교는 참고용 경고가 떠야 함.
7. 기존 통신공학/무선공학 `?kind=`, `?unit=`, K-water `?round=` 링크 동작 및 기존 로컬 기록 유지 여부 확인.
8. 360px 모바일/키보드/Console 검사. CI의 JS 구문 검사 통과는 실제 브라우저 Console 0건을 입증하지 않는다.
