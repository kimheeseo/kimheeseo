# 코레일 복원 PDF · 창작 응용 2회 반영 보고 (2026-11-23)

## 변경 요약

- 사용자 제공 PDF 40쪽(30문항·해설)을 원본 그대로 공개 경로에 연결. 민간 복원모의고사이며 코레일 공식 시험지와 구분.
- 기존 복원 30문항과 기존 응용 1회 30문항은 중복 추가하거나 변경하지 않았다.
- 30문항의 주제 순서에 대응하는 새 **창작 응용 2회**: 5지선다, 통신·전기 기초 20문항 + 무선·전자기 10문항. 개념 확인과 1~3단계 계산을 중심으로 작성했다. 난이도는 학습용 분류이며 실제 시험과의 통계적 동등성은 검증하지 않았다.
- 정답은 0부터 시작, 새 ID `KORAIL-2026H1-P2-01`~`30`. 기존 저장 키·ID·URL 유지.
- 과목별 문제은행, 학습 기록·오답·북마크·메모, 오류 신고와 출처·상태 표시 연동. 새 질문에 원본 PDF 쪽수를 허구로 표시하지 않음.
- 코레일 안내 페이지에 원본 PDF 보기/다운로드, 기존·신규 세트의 과목별 학습 링크, 전체 30문항과 해설 미리보기. 홈 기관 카드에서 진입.

   - 24개 수치 문제를 별도 수식으로 재계산해 정답 선택지 대조. 기존 4,024문항은 이전 해시·개수로 내용·ID 보존 검사.
   - 제공 PDF와 업로드 파일 SHA256 동일: `cf741754a0ace5f29a1c458292cab757633ca48914ea930115188600a09d7012`.
   - JS 125블록·JSON 63개 구문 검사, 활성 4,054문항·38페이지 메타·KaTeX만 CDN 허용, JSON 미러 63개와 레거시 은행 미러 2개 일치.
2. 브라우저에서 `/korail-2026/` 방문 → PDF 링크, 전체 창작 30문항, 14개 KaTeX 수식 정상 표시(오류 0), 검토 중으로 잘못 분류된 신규 문항 0.
3. 새 `?kind=코레일 기출 응용 2회` 링크: 통신 20 / 무선 10문항 필터. 검증 전용을 켜면 0, 끄면 각 세트 출제 가능. 통신 신규 1번 답안 제출·북마크·메모 후 새로고침하여 보존 확인. 창작 표시·출처·잠정 답안 표시 확인.
4. 360px iframe 3화면(코레일, 통신, 무선)에서 가로 넘침 없음. 새 무선 문항 출제 후에도 넘침 없음. 브라우저 사이트 콘솔 오류 0(브라우저 확장 기능 자체의 오류는 제외).
5. 신규 1번의 오류 신고를 해설 오류로 선택하고 메모 입력 → Issue URL의 문항 ID·사유·메모 자동 채움 확인. Issue는 제출하지 않음.
6. GitHub 브라우저 CI에 코레일·새 유형 통신/무선 URL을 추가했다. 실제 CI/Pages 완료 여부는 해당 커밋의 Actions에서 확인한다.
