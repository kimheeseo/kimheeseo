## 구성
첨부한 **무선공학.pdf(27페이지)**를 기반으로 제작한 학습용 3지선다 퀴즈입니다. 기존 500문항 중 **256문항은 무선공학 PDF와 동일하게 수록된 신호·변조·디지털 전송의 공통 기초 단원을 바탕으로 재구성**하고, **244문항은 전자파·안테나·급전선·전파전파·페이딩·무선망·이동통신·위성/레이더** 등 뒤쪽 단원에서 새로 구성했습니다.

## 추가 200문항 출제 비율

첨부 이미지의 16문항 출제 비중을 추가 문항에 적용했습니다. Ch5=3, Ch7=2, Ch8=4, Ch9=3, Ch10=2, Ch11=2(총 16)입니다. 비례 계산 결과 37.5문항인 Ch5·Ch9에서는 Ch5를 올림(38문항), Ch9를 내림(37문항)하여 총 200문항을 맞췄습니다.

| PDF 단원 | 기존 | 추가 | 최종 | 최종 비율 |
| --- | ---: | ---: | ---: | ---: |
| Ch1 신호·시스템 | 60 | +0 | 60 | 8.6% |
| Ch2 음성 디지털 부호화 | 57 | +0 | 57 | 8.1% |
| Ch3 아날로그 변조 | 68 | +0 | 68 | 9.7% |
| Ch4 디지털 변조 | 71 | +0 | 71 | 10.1% |
| Ch5 안테나 이론 | 63 | +38 | 101 | 14.4% |
| Ch6 안테나 실제 | 15 | +0 | 15 | 2.1% |
| Ch7 급전선 이론 | 30 | +25 | 55 | 7.9% |
| Ch8 전파 전파 이론 | 46 | +50 | 96 | 13.7% |
| Ch9 고정통신 시스템 | 45 | +37 | 82 | 11.7% |
| Ch10 이동통신 시스템 | 30 | +25 | 55 | 7.9% |
| Ch11 위성통신 시스템 | 15 | +25 | 40 | 5.7% |
| **전체** | **500** | **+200** | **700** | **100%** |

Ch5는 전자파와 주파수 분류·전자파와 안테나 이론·안테나 파라미터를 합쳤으며, Ch8은 전파 전파이론·페이딩·전리층을 합쳐 표시합니다. **전체 문제 구성 보기** 버튼으로 확인할 수 있습니다.

추가 200문항은 핵심 개념의 역방향 응용 120문항과 공식 계산 80문항으로 구성했습니다. 원본 기반의 학습용 재구성 문제이므로 모든 문항에 대한 외부 기출 검증이 이루어진 것은 아닙니다.

## 주요 기능
- 총 **700문항**, 각 문항 **보기 3개 / 정답 1개**
- 단원별·무작위·순차 출제, 10·20·50·100·전체 문항 선택
- 답 선택 시 즉시 채점, 오답/정답 해설, 원본 PDF 페이지 표기
- **재접속해도 풀이 이력·정답률·오답 목록 유지** (브라우저 로컬 저장)
- **오답만 다시 풀기**, 즐겨찾기, 학습 기록, JSON 백업/복원
- 모바일·PC 브라우저 지원, 다크모드

## 404 오류가 뜨는 경우
[GitHub Pages 설정 열기](https://github.com/kimheeseo/kimheeseo/settings/pages) → **Build and deployment** → Source: `Deploy from a branch` → Branch: `main` → Folder: `/(root)` → **Save**.

사이트 주소는 `https://kimheeseo.github.io/kimheeseo/quiz500/wireless-quiz-500/`입니다. 배포가 활성화되지 않은 경우 주소는 404로 보입니다.

## 학습 기록 주의 사항
학습 기록은 **현재 기기·브라우저의 localStorage**에 저장됩니다. 웹사이트와 파일(`file://`)로 실행할 경우 브라우저 저장 공간이 서로 달라 기록이 공유되지 않을 수 있습니다. **브라우저 데이터 삭제, 시크릿 모드, 다른 기기**에서는 기록이 유지되지 않을 수 있으니 `학습 기록 → 기록 백업` 기능을 이용하세요.

원본 PDF는 저작권·공유 권한 확인 전 공개 저장소에 업로드하지 않았습니다. 원본 필기와 수식·용어를 대조해 사용하세요. 이 문제은행은 외부 검증을 완료한 공식 기출문제가 아닙니다.
