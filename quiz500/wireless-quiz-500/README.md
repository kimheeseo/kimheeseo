## 단원별로 바로 문제 풀기

앱 학습 홈 → **전체 문제 구성 보기** → 원하는 단원의 **전체 풀기** 버튼을 선택하세요. 해당 단원의 모든 문항만 출제됩니다. 11개 단원이 각각 별개의 풀기 버튼으로 제공됩니다.

[통합 Quiz500 홈페이지](https://kimheeseo.github.io/kimheeseo/quiz500/)의 무선공학 단원별 구성 표에서도 **전체 풀기**를 선택해 해당 단원의 퀴즈를 바로 시작할 수 있습니다.

## 주요 기능

- 총 **760문항**, 각 문항은 3개 보기 중 정답 하나 선택
- 단원별 학습, 무작위 / PDF 페이지순 출제, 10·20·50·100·전체 문항 출제
- 답안 선택 즉시 채점, 정답 해설, 원본 PDF 쪽 표기
- **오답 다시 풀기 / 즐겨찾기 / 학습 기록 자동 저장 / 기록 JSON 백업·복원**
- 모바일과 PC 브라우저 지원, 다크모드
- 브라우저를 다시 열어도 **오답 및 정답률이 초기화되지 않습니다**

## 페이지가 404일 경우

저장소의 [Settings → Pages](https://github.com/kimheeseo/kimheeseo/settings/pages)에서 Source를 `Deploy from a branch`, Branch를 `main`, Folder를 `/(root)`로 설정해야 합니다.

학습 기록은 **기기·브라우저의 localStorage**에 보관됩니다. 다른 기기와 자동 동기화되지 않으며, 브라우저 기록을 지우면 복구되지 않을 수 있습니다. 중요 기록은 백업하세요.

원본 PDF는 공개 저장소에 포함하지 않았습니다. 문제은행은 PDF를 기반으로 재구성된 학습 콘텐츠이며 원본과 전 문항을 독립적으로 검증 완료한 공식 문제는 아닙니다.
