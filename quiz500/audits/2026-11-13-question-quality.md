# 3단계 문제은행 신뢰성·중복 점검

기준: 2026-11-13 / 저장소 기준 커밋 bbf48d88277b34c5ae3707c350ac2a8d3866c320.
대상: 통신공학과 무선공학의 실제 실행 배열. 자동 데이터 검사이며 문제 전체의 사실 검증이나 원문 대조를 의미하지 않는다.

## 데이터 점검
- 통신공학 등록 레코드 1,762개 중 본문과 선택지가 빈 14개는 실행 시 풀이 목록에서 보류한다. 원본 데이터는 보존하며 실제 학습 목록 1,748개다.
- 통신공학 40개 ID가 서로 다른 문항에서 반복되었다. 원본을 삭제하지 않고 로드 시 두 번째 이후 항목에 일관된 ID 접미사를 붙여 1,748개 활성 문항의 ID를 분리한다. 이전 ID는 최초 항목에 유지해 기존 동작에서 표시·기록되던 문항과의 연결을 보존한다. 이전의 중복 ID 기록이 원래 어떤 시험을 의도했는지는 복원할 수 없다.
- 통신공학 원본 또는 선택지의 사설 영역 문자를 포함한 활성 문항 287개는 화면 출력 손상 가능성이 있어 자동 채점 보류한다. 이는 복원 완료가 아니라 자동 탐지에 따른 안전 조치다. 기존 정답과 설명 데이터는 원본에 보존된다. 원래 정답 미등록 324건과 겹침을 제외하면 신규 채점 보류는 140건으로, 보류 전체 464건이다.
- 무선공학 2,156건 중 문제·선택지·정답이 완전히 같은 그룹 106개, 추가 회차 레코드 126건을 기본 출제와 기본 문제은행 목록에서 중복 제거해 2,030건을 보인다. 각 회차 원본, 정답·해설, 문제 ID, 기존 즐겨찾기·오답은 삭제하지 않았다. “같은 문제가 출제된 다른 시험 회차도 모두 표시” 옵션을 켜면 회차별 2,156건을 다시 볼 수 있다. 오답 및 즐겨찾기 복습은 회차별 기록을 유지한다. 개별 시험 원문의 동일성은 대조하지 않았다.
- 표기상 기출·응용·복원과 일반 학습문제를 구분하며, 출처의 존재만으로 원문 정답이나 해설의 정확성을 보증하지 않는다. 표기 또는 확인 근거가 없는 것은 미확인으로 둔다.

## 문항별 안내와 신고
- 풀이 및 문제은행 상세에 출처 표기, 자동 점검과 개별 원문 대조의 구분, 상태와 신고 메뉴를 추가했다.
- 신고 링크는 GitHub 공개 이슈 작성 화면에 제목·문항 ID·출처·오류 유형을 채워 연다. 실제 제출은 이용자가 직접 하며 GitHub 로그인 또는 권한이 필요할 수 있다. 개인정보를 적지 않도록 안내한다. 제출 또는 접수는 자동으로 보장되지 않는다.
- 통신공학의 사설 영역 문자 포함 287건 중 저장소에서 해당 시험지 경로를 확인한 국가직 171건과 지방직 34건은 PDF를 열 수 있게 했다. 방송통신 11건은 기존 원문 이미지 표시 경로를 유지한다. 나머지 71건은 연결 가능한 원문을 확인하지 못했다. 링크 가능한 PDF에 실린 문제의 문구·정답을 이번 단계에서 개별 대조한 것은 아니다.
- 채점 보류 응답이 통신공학 누적 정답률 분모에 들어가지 않도록 누적 정답률을 채점된 정답+오답 횟수 기준으로 변경했다. 풀이 횟수는 보류를 포함한다.

## 검증과 제한
- 기존 재현 절차에서 2024년도 지방공무원 9급 선택 시 2024년도 문항이 표시되는 것을 원격 브라우저 미리보기에서 확인.
- 통신공학의 정답 선택·즐겨찾기와 새로고침 후 풀이 통계, 무선공학의 중복 제외 2,030건 및 회차 모두 보기 2,156건 전환 확인.
- 오류 신고 항목을 펼치고 ID와 유형이 포함된 링크 생성 확인. 실제 공개 이슈는 작성·제출하지 않았다.
- 코드 문법을 확인했다. 각 원문 PDF 본문의 전수 표시, 원문·정답·해설의 사실 대조, 전체 링크, 모바일 실기기 시험은 수행하지 않았다.
- 개별 원문·정답·해설을 새로 확인 완료한 문항은 0건이다. 기존 검토 여부가 데이터에 일관되게 표현되지 않아 전체 미검토 문항을 확정할 수 없다. 기존 완료 항목까지 일괄 미검토라고 단정하지 않는다.
