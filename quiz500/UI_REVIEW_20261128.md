- 서울교통공사 사무직 자료 문의·한전KPS 학습 사례 및 K-water 수험생·재직자 경험담.
- 관련 업데이트·README·파생 통계·공유 메타. 전용 이미지 파일·사이트맵은 발견되지 않았습니다.

- 서울교통공사 신호직 야간근무, 철도공기업 현직 조언, 사무직 합격 준비 후기 3건 및 코레일의 연결 요약.
- 서울교통공사 채용 지연·보수·근무 소감과 기존 익명 학습·근무 사례 묶음.
- 9호선 필기 결과 화면과 자기소개서 부적격 결과 이미지의 개인 사례. 파생 통계도 제거했습니다.
- K-water 전자통신 추가 참고자료: 원문 링크가 없는 재직자 의견·자기소개서 사례·시험 분석 묶음.

- 전체 HTML·Markdown과 JSON으로 삽입하는 HTML을 함께 검사: 60개 문서, 내부 참조 746개, 누락 파일·앵커 0개. 외부 서버의 현재 응답 상태 검사는 범위에 포함하지 않았습니다.
- JSON 미러 63개와 기존 문제은행 미러 2개 일치. 전체 JavaScript·JSON 구문 검사 및 git diff 공백 검사 통과.
- 데스크톱 브라우저에서 홈·기관별 이동, 스크롤 스파이, 카드 정렬, 더보기, 모의고사 설정·검증 문항 부족 시 시작 제한, 기록 이전 화면 확인.
- 320px·375px·768px iframe 렌더링으로 반응형 검사. 모바일 가로 넘침 없음, 하단 메뉴 터치 높이 약 54px, 기관 카드 4개 높이·주 버튼 위치 일치. 375px에서 다크 모드 실제 렌더링 확인.
- 주요 텍스트·뱃지 토큰의 정적 대비 검사: 라이트 최소 5.56:1, 다크 최소 7.07:1. 전체 WCAG 자동·보조기기 적합성 감사를 수행한 것은 아닙니다.
- 신규 방문·복습 가능한 문항 있음·대기 문항 검증 제한·복습 없음·로드 실패·보조 데이터 실패는 격리한 홈 테스트에서 확인했습니다. 실제 사용자 기록을 초기화하지 않았습니다.
- 검증 승인 문항이 현재 0개이므로 실제 데이터로 일반 모의고사를 시작할 수 없는 기존 제한은 유지됩니다. 출제 가능한 승인 문항이 있는 경우의 시작·채점·시간 제한은 기존 격리 테스트에서 검증했습니다.
