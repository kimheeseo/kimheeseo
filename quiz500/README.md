## 단원·난이도별 학습

통신공학은 1,069문항, 무선공학은 1,050문항이며, **단원별**, **난이도별(하·중·상)**, **단원+난이도 조합** 출제가 가능합니다. 통합 홈페이지의 전체 문제 구성표에서는 원하는 단원의 **전체·하·중·상** 버튼을 선택해 바로 학습할 수 있습니다.

난이도는 학습용 추정 분류입니다. 기본 개념 암기(하), 응용·계산(중), 복합 개념 및 심화 계산(상)을 기준으로 배정하였으며 공인된 난이도 등급은 아닙니다.

기존 문제은행의 ID와 풀이 기록은 유지하고, JSON·CSV·웹앱에 새로운 문항과 출처 구분을 함께 반영했습니다. 원본 PDF는 저장소에 올리지 않았습니다.
