## 단원·난이도별 학습

통신공학은 1,093문항, 무선공학은 1,074문항이며, **단원별**, **난이도별(하·중·상)**, **단원+난이도 조합** 출제가 가능합니다. 통합 홈페이지의 전체 문제 구성표에서는 원하는 단원의 **전체·하·중·상** 버튼을 선택해 바로 학습할 수 있습니다.

난이도는 학습용 추정 분류입니다. 기본 개념 암기(하), 응용·계산(중), 복합 개념 및 심화 계산(상)을 기준으로 배정하였으며 공인된 난이도 등급은 아닙니다.

### 대분류 메뉴 및 LTE-R 3D 시뮬레이션 추가

- 서울교통공사·코레일 면접 페이지에 **6개 큰 카테고리 → 세부 메뉴 → 질문·답변**의 3단 구조를 적용했습니다. 최초에는 상위 카테고리 6개만 보이고, 각 카테고리를 클릭하면 해당 세부 메뉴만 나타납니다.
- 상위 분류: **채용·지원 정보 / 근무지·직무 안내 / LTE-R·통신기술 / 면접 전형·실전 대비 / 최근 뉴스·면접 후기 / 업데이트·출처** (코레일은 뉴스와 업데이트 구분).
- [LTE-R 3D 시뮬레이터](./interview/rail-lte-r-3d.html): Three.js 기반 교육용 열차·선로·기지국 A/B/C·백홀·코어망·관제센터 3D 모델. 열차 이동, 기지국 전환(핸드오버), 데이터 흐름을 애니메이션으로 표시하고 재생·일시정지·속도·시점(측면/상단/입체)·확대와 무선 링크 표시를 제어할 수 있습니다.
- [기존 LTE-R 2D 가이드](./interview/rail-lte-r.html)에도 3D 실행 버튼과 미리보기를 추가했습니다.
