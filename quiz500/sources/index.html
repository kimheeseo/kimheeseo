통신공학·무선공학·K-water 모의고사·코레일 및 공무원 자료의 출처 성격과 이용 원칙을 구분합니다. 일부 예전 문제는 원문·정답·해설에 대한 개별 대조가 완료되지 않았으며, 검증 상태 배지가 내용 정확성을 보증하는 것은 아닙니다.

자료 유형별 이용 원칙

유형기준과 표시
공식 공개기관이 공개한 채용공고·시험 통계·기출문제 원문은 공식 링크 중심으로 안내하고, 재배포 허가가 확인되지 않은 원문은 전문을 복제하지 않습니다.
자체 창작교육 목적으로 독립 작성한 응용문제·예상문제입니다. 실제 기관에서 출제한 기출로 표기하지 않습니다.
외부 참고민간 강의자료·블로그·커뮤니티·원문 추출 자료는 별도 검증이 필요합니다. 해당 기관 공식 발표가 아닌 정보에는 참고용 표시를 합니다.

문항 출처의 ‘메타 확인일’은 출처 필드의 기록·점검 날짜이지 문제 자체의 정답 검증 완료일이 아닙니다.

기출문제와 저작권

공개된 기출·외부 원문은 원문 링크·출제 범위 안내를 우선하고, 출처 표시만으로 전체 재게시 권한이 확보되었다고 판단하지 않습니다.

기존 원문 재게시 가능성이 있는 문항을 검토 후보 CSV로 추출했습니다. 이 파일은 출처·표제·문항 유형에 근거한 우선 검토 목록으로, 원문과 문장 단위 대조를 완료한 확정 목록이 아닙니다. 사용자 확인 전 삭제 또는 교체하지 않습니다.

문항 상태와 오류 신고

문항 상태는 verified(검증됨), auto(미검증), review(검토 중) 세 가지입니다. 정답·해설 검증 완료 지정은 승인 목록에서만 수행합니다. 검토 중 문항은 자동 채점하지 않습니다.

문항 화면에서 정답/해설 오류 신고를 선택하고 사유(정답 오류·해설 오류·문제 오타·수식 깨짐·기타)와 메모를 적으면 해당 문항 ID가 채워진 GitHub Issue 작성 화면이 열립니다. 로그인 후 본인이 제출해야 접수됩니다. 공개 이슈에 개인정보를 남기지 마세요.
