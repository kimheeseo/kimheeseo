## 문제 구성과 검증 주의 사항

기존 700문항에 300문항을 추가했습니다. 신규 문항은 기존 PDF 기반 개념 두 가지를 결합해 의미를 정확히 구분하도록 만든 **통합형 문제**입니다. 원본에 없는 새로운 학술 사실을 인용했다는 뜻은 아닙니다. 다만 두 개념의 연결과 난이도 표시는 자동 생성·분류를 포함하므로, **전 문제를 독립 검수한 공식 문제은행은 아닙니다.**

## 기능
- 3·5지선다 혼합, 답변 즉시 채점 및 해설
- 단원별·난이도별·단원+난이도 조합 출제, 전체 문제 구성표에서 바로 시작
- PDF 페이지 안내, 오답 모아 풀기, 즐겨찾기, 학습 이력 및 정답률 저장
- 기존 브라우저의 풀이 기록은 재접속 후 유지 (동일 도메인·동일 브라우저 기준)
- 문제은행 검색에서 난이도·단원·유형 필터
- **HTML 다운로드·스마트폰 파일 저장 버튼은 제공하지 않음**
